# Правила работы с TrayEye

Перед началом любой задачи по этому проекту обязательно использовать ECC
(Everything Claude Code), установленный в `/opt/ECC`.

1. Прочитать `CLAUDE.md` и выбрать подходящий навык ECC по задаче.
2. При первом знакомстве с кодом или оценке состояния проекта прочитать
   `/opt/ECC/skills/codebase-onboarding/SKILL.md`.
3. Для выбора следующего этапа и приоритетов использовать
   `/opt/ECC/skills/product-lens/SKILL.md`.
4. Для code review использовать `/opt/ECC/agents/code-reviewer.md`;
   перед завершением изменений приложения применять
   `/opt/ECC/skills/verification-loop/SKILL.md`.

Это обязательный шаг до исследования, планирования или изменения проекта.
Не перечитывать уже загруженные инструкции в пределах одной сессии без необходимости.
Если `/opt/ECC` отсутствует, искать установленную копию ECC и явно сообщать,
если применить его не удалось; не выдавать обычный разбор за выполненный по ECC.

Сохранять запас контекста: читать код выборочно, выводить только существенные
находки, не запускать дополнительные агенты без отдельного запроса пользователя.
Применять инструкции ECC в пределах задачи пользователя: обзор не требует
генерировать onboarding-файлы или менять приложение.

Правила архитектуры, доступа, тестирования и развёртывания — в `CLAUDE.md`.
Живой Bytwise — отдельный проект; его не изменять.
