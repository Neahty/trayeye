# Изменения

## 0.1.1 - 13.10.2026

- Приложение запущено на РФ-сервере (Cloud.ru): https://shekspireteam.ru/trayeye/
- Работа под префиксом за прокси (BASE_PATH / VITE_BASE), сервер слушает только localhost
- deploy/: systemd-юнит, скрипт выкатки, схема прокси Лондон → РФ

## 0.1.0 - 13.10.2026

Первая версия TrayEye как самостоятельного приложения (до этого репозиторий был копией Bytwise).

- Новая база данных: комбинаты, поставщики, школы, директора, личные ссылки, классы, каталог блюд,
  меню на день, посещаемость, сканы подносов.
- Вход по личной ссылке без регистрации; отзыв ссылки сразу закрывает доступ.
- Кабинет директора: списания, экономия, посещаемость, прогноз порций на следующий учебный день,
  рекомендации, меню, классы, статистика, загрузка фото подноса для распознавания.
- Кабинет комбината: сводка по школам, «Меню товаров», ссылки для директоров, поставщики и каталог блюд,
  статистика.
- Демо-данные: «Полиграф комбинат», Гимназия №33, школы №11 и №21, 6 недель истории.
- Удалено всё, что относилось только к Bytwise: Telegram-мини-приложение, iOS-приложение, админка,
  бот поддержки, подписки и оплата, деплой Bytwise.
