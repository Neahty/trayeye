# Бизнес - IT компания (АгроСкан)

Техническая база - бот Bytwise (имена сервисов, путей `/opt/bytwise`, бота @Bytwise_bot и systemd-юнитов не менять - на них завязан деплой).

## Деплой на сервер

Прод деплоится автоматически из GitHub Actions - ПК пользователя не нужен.

**Как выкатить обнову:** когда пользователь просит «выкатить на сервак» / «выкати обнову» / «кинь на сервак» - закоммить с меткой `[deploy]` в сообщении коммита и запушить текущую `claude/*` ветку. GitHub Actions (`.github/workflows/auto-deploy-claude.yml`) сам вольёт ветку в `master` и задеплоит через `deploy.yml`.

**Важно:** без явной просьбы выкатить - метку `[deploy]` НЕ ставить. Тогда ветка просто остаётся веткой и в прод ничего не уезжает.
