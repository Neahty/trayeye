# Как внести вклад в TrayEye

Спасибо, что хотите помочь проекту. Короткий порядок работы:

1. Создайте ветку от `master`: `feature/<что-делаем>` или `fix/<что-чиним>`.
2. Делайте небольшие понятные коммиты. Сообщение коммита пишем по-русски, в повелительном или
   прошедшем времени: «Добавлен отчёт по блюдам», «Исправлен подсчёт остатков».
3. Перед отправкой запустите проверки:
   - сервер: `cd server && npm ci && npm run test:ci` (нужен `TEST_DATABASE_URL`, иначе тесты API пропускаются)
   - веб: `cd web && npm ci && npm test && npm run build`
4. Откройте Pull Request, заполните шаблон, дождитесь ревью от владельцев кода (`CODEOWNERS`).
5. В `master` изменения попадают только через Pull Request.

## Важно

- Не коммитьте секреты: `.env`, токены, ключи. Образец переменных лежит в `.env.example`.
- Новые таблицы добавляйте в `server/src/db/schema.sql` идемпотентно (`IF NOT EXISTS`).
- Любой запрос кабинета должен быть ограничен своей школой или своим комбинатом.

## Сообщить о проблеме

Используйте раздел **Issues** и выберите подходящий шаблон. Об уязвимостях пишите по
инструкции из [SECURITY.md](SECURITY.md), а не в публичные Issues.
